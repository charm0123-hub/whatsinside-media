개인정보처리방침

시행일: 2026-11-23

1. 사용 목적

이 도구는 계정 소유자 본인의 구글 캘린더(읽기 전용)와 구글 할 일 목록을 본인의 업무 화면에 표시하고, 본인이 요청한 할 일을 추가·완료 처리하는 데만 사용합니다.

2. 접근하는 정보

구글 캘린더 일정(제목·시간), 구글 할 일(제목·마감일·완료 여부).

3. 보관과 공유

정보는 소유자 본인의 컴퓨터에서만 처리하며 제3자에게 판매·공유하지 않습니다. 접근 권한 정보는 본인 컴퓨터에 암호 보호 파일로만 보관합니다.

4. 권한 철회

구글 계정 > 보안 > 서드파티 액세스에서 언제든 권한을 해제할 수 있습니다.

5. Google API 사용

Google API에서 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

6. 문의

계정 소유자 본인(지원 이메일은 Google 동의 화면에 표시)
